🔗 เปลี่ยน Script URL

หากต้องการเชื่อมกับ Google Sheets อื่น

วิธีตั้งค่า Google Apps Script

ขั้นตอนที่ 1 — เปิด Google Sheets
สร้าง Google Sheets ใหม่ หรือใช้ไฟล์ที่มีอยู่แล้วก็ได้
ขั้นตอนที่ 2 — เปิด Apps Script
ที่เมนูบน: Extensions → Apps Script
ขั้นตอนที่ 3 — วาง Code.gs
ลบโค้ดเดิมออกทั้งหมด แล้ววางโค้ดจากไฟล์ Code.gs ที่ดาวน์โหลดมา
ขั้นตอนที่ 4 — Deploy
คลิก Deploy → New deployment
· Type: Web app
· Execute as: Me
· Who has access: Anyone (หรือ Anyone with Google account ถ้าต้องการปลอดภัยขึ้น)
คลิก Deploy → อนุญาต permission → คัดลอก Web app URL
ขั้นตอนที่ 5 — วาง URL
นำ URL ที่ได้มาวางในช่องด้านบนแล้วกด บันทึก
💡 ทำครั้งเดียว — ทีมทุกคนใช้ URL เดียวกัน เปิดไฟล์ HTML บนเครื่องตัวเองได้เลย ข้อมูลเก็บที่ Sheets กลาง
